# Ventanilla Viajes — Vuelo virtual

Página web de agencia de viajes con una experiencia en primera persona: el visitante aborda un avión, se sienta junto a la ventanilla, sobrevuela cada destino con su música y su paquete, y al aterrizar deja sus datos para recibir la cotización.

- `index.html` — página principal (destinos, precios, contacto).
- `vuelo.html` — el vuelo virtual en 3D.
- `datos.js` — **aquí se edita todo**: nombre de la agencia, WhatsApp, correo, RNT, paquetes, precios, fotos y la azafata.
- `vendor/three.min.js` — librería 3D (three.js r128, licencia MIT).
